# Чек-лист: поиск адреса на шаге «Адрес регистрации» (е-ОСАГО, СберБанк Онлайн)

## Поиск и подсказки

1. Поиск по полному адресу: город, улица, дом
2. Поиск по названию улицы так, как оно записано в паспорте
3. Поиск по адресу в том виде, в каком его показывает подсказка
4. Поиск с сокращениями («г.», «ул.», «р-н») и без них
5. Буквы «е» и «ё» в названии улицы
6. Номер дома с литерой и корпусом (71а, 71/1, к. 2)
7. Опечатка в названии улицы
8. Ввод в латинской раскладке (`Pfbycr` вместо `Заинск`)

## Поле ввода

9. Пустое поле и поле из одних пробелов
10. Спецсимволы и эмодзи в поле
11. Кнопка «×» очищает поле и список подсказок

## Переход дальше

12. «Продолжить» без выбранного адреса
13. «Продолжить» после выбора адреса из подсказок — открывается следующий шаг
14. Ручной ввод адреса через «заполнить адрес вручную»
15. Пропажа сети во время поиска — понятное сообщение, приложение не зависает
