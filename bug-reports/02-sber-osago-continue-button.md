# BUG-02. ОСАГО → «Адрес регистрации»: кнопка «Продолжить» активна, но не реагирует, когда адрес не найден

## Общая информация

| Поле | Значение |
|------|----------|
| Продукт | СберБанк Онлайн, мобильное приложение |
| Компонент | Оформление е-ОСАГО → шаг «Адрес регистрации» |
| Устройство | iPhone 13, iOS 26.5, СберБанк Онлайн 16.13.0 (3) |
| Дата | 14.11.2026 |
| Severity | Minor |
| Priority | Medium |
| Связан с | [BUG-01](01-sber-osago-address-search.md) |

## Предусловия

Пользователь дошёл до шага «Адрес регистрации» при оформлении е-ОСАГО.

## Шаги воспроизведения

1. Ввести в поле «Населённый пункт, улица, дом» запрос, по которому адрес не находится, например `Заинск никифорова`.
2. Убедиться, что отображается «Адрес не найден».
3. Нажать «Продолжить».

## Фактический результат

Кнопка «Продолжить» отображается так же, как при найденном адресе (зелёная, выглядит активной).
При нажатии ничего не происходит: перехода на следующий шаг нет, сообщения нет.

## Ожидаемый результат

Пока адрес не выбран из подсказок, кнопка «Продолжить» неактивна (серая), либо при нажатии
показывается сообщение, что нужно выбрать адрес из списка.

## Обоснование Severity и Priority

**Severity: Minor.** Функция оформления не ломается, но пользователь не понимает, почему не может
пройти дальше, и может решить, что приложение зависло.

**Priority: Medium.** Вместе с BUG-01 усиливает ощущение «сломанного» шага и повышает вероятность,
что пользователь бросит оформление.

## Скриншоты

См. скриншоты 2 и 3 в [BUG-01](01-sber-osago-address-search.md#скриншоты): при «Адрес не найден»
кнопка «Продолжить» отображается активной.
